PIPELINE ARCHITECTURE

How the AI works

End-to-end deep learning inference pipeline from raw input string to multi-class distribution.

01

Input

Your raw text is submitted securely to the FastAPI inference endpoint.

02

Preprocessing

The text is normalized, tokenized into integer tokens, and padded to a uniform sequence of 50 tokens.

03

BiGRU Model

A deep Bidirectional GRU reads the sequence both forwards and backwards, synthesizing context from both directions.

04

Prediction

A softmax activation layer produces a normalized probability distribution across the 6 target emotions.
